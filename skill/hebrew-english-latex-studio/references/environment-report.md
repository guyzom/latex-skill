# צילום מדוד של סביבת הבנייה

כאשר אותה גרסת סקיל מתנהגת אחרת בשתי סביבות, שמור בכל אחת דוח:

```bash
python3 scripts/environment_report.py --output /path/to/project/environment.json
```

תיקיית היעד צריכה להתקיים. שמור את הדוח **מחוץ לעץ הסקיל**, לצד המקור,
ה־PDF ולוג הבנייה. בלי `--output` מתקבל JSON ב־stdout. הכלי אינו מקמפל TeX
ואינו מחליף את `doctor.py` או את `build.sh`.

## מה נמדד

הדוח כולל את גרסת הסקיל, Python ומערכת ההפעלה; גרסאות כלי LuaLaTeX,
kpsewhich ו־Poppler; גרסאות ספריות ה־QA מול baseline; חתימות קובצי
מנגנון מרכזיים, קבצי הפעלה ותלויות TeX נדרשות; ותוצאת אימות חבילת הגופנים.
הנתיבים המלאים של התלויות, שם המחשב ומשתני הסביבה אינם נכללים. קובצי
גופנים אינם מועתקים לדוח. רישיונות וחתימות מותרים נשארים בחבילה.

השדה `scope` הוא `required-build-dependencies`: זהו צילום **מוגבל** של
תלויות הדרושות לסקיל. הוא אינו מונה כל חבילת TeX מותקנת, ספריית מערכת,
קובץ שנקרא בפועל מתוך מסמך מסוים, קונפיגורציה או נתון בעל השפעה אפשרית.
לוג ו־`.fls` של הבנייה משמשים ראיות משלימות, לא תחליף לצילום.

## מצב וחתימת תוכן

`status=complete` פירושו שכל המדידות שהכלי ניסה לבצע הצליחו והתלויות
המוצמדות שנבדקו תואמות. הוא אינו אומר שכל המסמכים ייבנו או ייראו נכון.
כשחסרה תלות או לא ניתן לקרוא אותה, `errors` מפרט את הבעיה, המצב הוא
`incomplete` וקוד היציאה הוא 1. כשל בכתיבת הדוח או כשל כלי אחר מחזיר 2.
אל תתייחס לדוח חלקי כאל הוכחת תאימות.

`fingerprint_sha256` מחושב מתוכן ה־JSON בלי שדה החתימה עצמו, בקידוד UTF-8,
מפתחות ממוינים ומפרידי JSON קומפקטיים. אין חותמת זמן כדי שצילום חוזר של
אותה סביבה מדודה יהיה בר־השוואה. שינוי בחתימה מצביע על שינוי בנתונים
שנמדדו; חתימה זהה אינה הוכחה לזהות מלאה של סביבות או של פלטים עתידיים.

החתימה אינה חתימה דיגיטלית, אישור זהות הבודק או הוכחה שהדוח לא נערך.
הדוח אינו lockfile ואינו מתקין או משחזר את מערכת TeX. לבדיקת פלט יש לבנות
בשתי הסביבות ולהשוות גם את המסמכים עצמם.

הכתיבה מחליפה את קובץ היעד אטומית. קישור סמלי ביעד מוחלף כקישור, לא נכתב
אל התוכן שעליו הוא מצביע. אין זו מדיניות בנייה מקבילית או מערכת גיבוי.

## Runtime identity boundary (4.22.0)

The environment report verifies installed dependencies, not the actual font
resource chosen for a PDF. Use the separate framed runtime observation and
`check_runtime_fonts.py`; see `runtime-fonts.md`. These are registered-resource
checks, not an embedded-subset audit.
