\noindent
נתון אוסצילטור עם $H_0 = \hbar\omega(a^\dagger a + \tfrac12)$, ומצב qubit כללי.
אופרטורים: $\sin\theta$, $\cos\theta$, $\Tr(\dyad{\psi})=1$ — אם יוצאים tofu, חסר \code{[no-math]}.

\[ i\hbar\frac{\partial}{\partial t}\ket{\psi} = H\ket{\psi},\qquad
   \sigma_y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}. \]

\begin{defbox}[frametitle={הגדרה — שער הדמרד}]
$H=\tfrac1{\sqrt2}(X+Z)$, ומקיים $HXH=Z$. לטינית במתמטיקה: $\det(H)=-1$.
\end{defbox}

\noindent אופרטור הזהות נכתב $\id$, ומצב מעורב כללי הוא
$\rho=\half(\id+\vec a\cdot\vec\sigma)$ — אם במקום $\id$ מופיע סימן turnstile, מישהו
שבר את ה-macro \code{\textbackslash id} ב-preamble.
