{\LARGE\sffamily\bfseries\noindent Task handover process review\par}\medskip
\section{Executive summary}
A task handover should identify the current status, outstanding decision, and
responsibility for further work. The proposed process collects these details
in one short record.
\section{Scope and method}
The review concerns coordination when one task changes hands. It examines the
roles of status, responsibility, and the next action. No completion times or
actual outcomes have been measured.
\section{Findings}
A status description explains what has been completed. Responsibility identifies
who continues the work, while the next action states what needs to happen.
Each detail answers a different question.
\section{Limitations}
The process description alone cannot show whether the recipient has enough
information to proceed. That requires feedback from participants and review
of actual tasks.
\section{Recommended action}
Try a short handover record and ask the recipient to identify missing information.
Use that feedback to revise the record before extending use of the process.
