\section{תקציר}
מציגים את השאלה, את הממצא המבוסס העיקרי ואת הצעד הבא. זהו מבנה לדוגמה,
ולא דוח המכיל ממצאים שנחקרו.
\section{תחום ושיטה}
מגדירים את התקופה, המקורות, ההנחות ושיטת העבודה. מפרידים בין תצפית
לפרשנות ומציינים מידע חסר.
\section{ממצאים}
מארגנים את הראיות שנבדקו לפי השאלות החשובות לקורא.
\section{מגבלות}
מתארים אי־ודאות שעשויה לשנות את הפרשנות.
\section{פעולה מומלצת}
מקשרים בין כל פעולה מוצעת לראיות, ומציינים כיצד תיבדק ההתקדמות.
