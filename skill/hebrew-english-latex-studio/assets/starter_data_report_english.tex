{\LARGE\sffamily\bfseries\noindent Data report\par}\medskip
The table contains six synthetic records of a dimensionless variable. Each record
contributes equally to the unweighted mean.
\section{Variable definitions}
Let $x_i$ be the value of record $i$ and $n$ the number of records.
For this example, use the unweighted mean:
\begin{equation}\label{eq:mean}
\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i.
\end{equation}
