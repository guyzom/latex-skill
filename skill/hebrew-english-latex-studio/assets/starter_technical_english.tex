\section{Question and assumptions}
We calculate a weighted sum of a sequence of values. Assume that the values
and weights are given and that both sequences have the same length.
\section{Definition and derivation}
\begin{equation}\label{eq:weighted}
y=\sum_{i=1}^{n}w_i x_i.
\end{equation}
In \eqref{eq:weighted}, $x_i$ is an input value, $w_i$ its weight, and $n$ the
number of values.
\begin{exbox}[frametitle={A simple check}]
For $n=2$ and $w_1=w_2=1$, the result is $y=x_1+x_2$.
\end{exbox}
\section{Example implementation}
\begin{codebox}[frametitle={Python}]
\begin{asmblock}
\begin{lstlisting}[style=pystyle]
def weighted_sum(values, weights):
    if len(values) != len(weights):
        raise ValueError("Length mismatch")
    return sum(w * x for w, x in zip(weights, values))
\end{lstlisting}
\end{asmblock}
\end{codebox}
\section{Validation and limitations}
The implementation rejects sequences of unequal length. For two empty sequences
it returns zero, following the empty-sum convention. If the weights are
dimensionless, the result has the same units as the input values.
